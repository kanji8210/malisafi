1. PROPERTIES GRID
------------------
[malisafi_properties]

Description: Displays a grid of properties with filtering options

Parameters:
- type          : Filter by property type slug (e.g., "house", "apartment")
- status        : Filter by property status slug (e.g., "for-sale", "for-rent")
- location      : Filter by location slug (e.g., "new-york", "downtown")
- featured      : Show only featured properties (any value to enable)
- count         : Number of properties to display (default: 21)
- offset        : Skip this many properties (default: 0, useful for pagination)
- orderby       : Order by field (date, price, title, rand, etc.)
- order         : Sort order (ASC or DESC, default: DESC)

Examples:
[malisafi_properties count="9" orderby="price" order="ASC"]
[malisafi_properties type="house" status="for-sale" count="6"]
[malisafi_properties featured="1" count="3"]
[malisafi_properties location="downtown" count="12"]
[malisafi_properties count="12" offset="5"] <!-- Skip first 5, show next 12 -->
[malisafi_properties type="apartment" count="6" offset="0" orderby="price"]

==============================================
USAGE NOTES
==============================================

1. Multiple shortcodes can be combined on the same page
2. All shortcodes are responsive and mobile-friendly
3. Shortcodes respect plugin settings (currency, units, etc.)
4. Use WordPress's do_shortcode() function in templates
5. Shortcodes can be nested where appropriate
6. All user inputs are sanitized for security

==============================================
DEVELOPER NOTES
==============================================

To implement future shortcodes:

1. Add shortcode handler in public/class-public.php
2. Register in includes/class-core.php
3. Create corresponding template in templates/
4. Add necessary CSS in assets/css/public.css
5. Add JavaScript if needed in assets/js/public.js
6. Update this reference file
7. Add to plugin documentation
