# 🚀 Quick Start - Configuration des Pages Dashboard

## En 3 étapes simples

### Étape 1️⃣ : Allez dans votre Dashboard WordPress
```
Connectez-vous à /wp-admin
```

### Étape 2️⃣ : Vérifiez le widget "Malisafi Quick Setup"
```
Sur la page d'accueil du dashboard, vous verrez :
- Le nombre de pages manquantes
- Une barre de progression
- Un bouton "Complete Setup Now"
```

### Étape 3️⃣ : Créez toutes les pages en UN clic
```
Menu : Malisafi → Pages
Cliquez sur : "Create All Missing Pages"
✅ Terminé !
```

## ❓ Questions fréquentes

### Q: Les pages sont-elles vraiment créées automatiquement ?
**R:** Oui ! En un seul clic, toutes les 26 pages sont créées avec :
- ✅ Le bon titre
- ✅ Le bon slug (URL)
- ✅ Le shortcode correct
- ✅ La structure parent/enfant

### Q: Puis-je personnaliser les pages ?
**R:** Oui ! Après création, vous pouvez :
- ✅ Modifier le contenu
- ✅ Ajouter du texte
- ✅ Changer le design
- ⚠️ **Mais gardez le shortcode** pour que la page fonctionne

### Q: Et si je supprime une page par erreur ?
**R:** Pas de panique !
1. Allez dans Malisafi → Pages
2. Trouvez la page supprimée (marquée ⚠️)
3. Cliquez sur "Create"
4. La page est recréée !

### Q: Comment voir toutes les pages créées ?
**R:** Deux façons :
1. **WordPress** → Pages → Toutes les pages
2. **Malisafi** → Pages → Vue organisée par catégorie

## 🆘 Besoin d'aide ?

### Si les shortcodes ne fonctionnent pas
1. Vérifiez que le plugin est activé
2. Allez dans Réglages → Permaliens
3. Cliquez sur "Enregistrer" (même sans rien changer)

### Si une page affiche 404
1. Réglages → Permaliens → Enregistrer
2. Videz le cache si vous utilisez un plugin de cache

### Si le widget ne s'affiche pas
1. Vérifiez que vous êtes administrateur
2. Allez dans Options de l'écran (en haut)
3. Cochez "Malisafi Quick Setup"
