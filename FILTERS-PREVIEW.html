🚀 Fonctionnalités Principales

⚡ Filtrage AJAX

Filtrage en temps réel sans rechargement de page. Expérience utilisateur fluide et moderne.

📱 Responsive Design

S'adapte automatiquement à tous les écrans : desktop, tablette, mobile.

🎨 Design Moderne

Interface élégante avec animations douces, cartes blanches et ombres subtiles.

🔍 Multi-Filtres

10+ options de filtrage : prix, type, chambres, superficie, caractéristiques...

📊 Tri Avancé

8 options de tri : prix, date, superficie, nom (ascendant/descendant).

🎯 Vue Grille/Liste

Basculer entre vue grille et liste. Préférence sauvegardée automatiquement.

📝 Utilisation Simple

Ajoutez le shortcode sur n'importe quelle page :

[malisafi_properties_modern]

Étapes :

  1. Créer une nouvelle page : Pages > Ajouter
  2. Titre : "Recherche de Propriétés"
  3. Insérer le shortcode dans le contenu
  4. Publier la page
  5. Visiter la page pour voir le résultat !

⚙️ Administration

La page d'administration des propriétés utilise le même design moderne :

  • Accès : Propriétés > Toutes les propriétés
  • Filtres sur la gauche (comme le frontend)
  • Cartes de propriétés sur la droite
  • Boutons Modifier/Voir au survol
  • Informations de statut et ID
  • Vue grille/liste également disponible
